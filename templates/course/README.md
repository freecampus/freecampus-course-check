# First Steps

This is a minimal FreeCampus course starter. Replace the example content with
original, openly licensed teaching material. Keep the license and attribution
notices required for reused material; choose appropriate terms for your additions.

Install [Quarto](https://quarto.org/docs/get-started/), then run:

```sh
quarto preview docs
quarto render docs
```

The source is in `docs/`. Update `docs/_quarto.yml` when adding or moving pages.
Every course contains milestones; every milestone and unit has a challenge.
Community courses are ungraded. This starter has no progress-tracking component.
If you add one, explain that browser-local progress stays in the same browser,
profile, and device and may be lost when site data is cleared.

See the [structure and Action documentation](https://github.com/freecampus/freecampus-course-check)
for validation workflow setup and the full contract. The Action's initial release
must be merged and tagged before a consumer can use its documented release tag.
